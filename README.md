### What I'm building

- 🧭 **[PULSE](https://thepulseapi.com)** at Resolve Labs, where I'm the architect: a decision API that AI agents and software can call. Requirements and evidence go in; for every option, a verdict comes out: *fits*, *fails*, or *cannot tell*, with what is missing.
- 🔓 **[Open Pulse](https://github.com/mypulseapi/open-pulse)**: the open-source half. An MCP server that gives Claude, Cursor and Codex grounded decisions, plus the browser SDK. MIT licensed.
  - [`@thepulseapi/mcp`](https://www.npmjs.com/package/@thepulseapi/mcp) · [`@thepulseapi/sdk`](https://www.npmjs.com/package/@thepulseapi/sdk)
- 📚 **[Developer docs](https://developer.thepulseapi.com)**, written for people and for AI agents alike.

### How I like to build

- **Show the working.** A number I can't reproduce doesn't ship.
- **Let systems say "I don't know."** An honest *cannot tell* beats a confident guess.
- **Verify before you optimise.** Measure whether a decision worked before automating more of them.
